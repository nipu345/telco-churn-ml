# Telco Customer Churn Prediction

INFO 4604 Portfolio Project by Nikhil Pudtha.

Predicting which telecom customers will cancel, using the IBM Telco Customer Churn dataset (7,043 customers). Covers class balance, outliers, imputation, encoding, correlation checks, K-Means clustering and a logistic regression classifier.

- **View the project:** https://nipu345.github.io/telco-churn-ml/
- **Notebook:** `Telco_Churn_Portfolio_Project.ipynb`
- **Data:** `data/telco_churn.csv` (source: [IBM](https://github.com/IBM/telco-customer-churn-on-icp4d))
